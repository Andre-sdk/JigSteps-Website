# JigSteps — Website

Source for the [JigSteps](https://jigsteps.app) marketing and documentation site,
hosted on GitHub Pages.

JigSteps is an Android app for calculating precise support distances for
jig-based powered grinding equipment — built around the Tormek T-8, but
supporting any wheel-type or flat-type grinder.

## What's here

Static HTML/CSS, no build step, no frameworks.

- `index.html` — landing page
- `guide.html` — full usage guide
- `equipment.html` — detailed equipment guide
- `calculator.html` — online setup calculator
- `changelog.html` — release notes
- `privacy.html` — privacy policy
- `contact.html` — contact details
- `sitemap.html`
- `assets/` — images, diagrams, logo
